Which model × skill combinations change how a coding agent behaves?

Overview

  • Goal: find model × skill combinations that change how the coding agent behaves, to choose agent conditions for the user study.
  • What we ran: 3 models × 6 set-ups (baseline + 5 skills) on 2 study tasks with simulated users; 360 sessions.
  • What we measured: 9 agent-side behaviours, defined in Setup.
  • How to read the grids: each cell is the change vs baseline in percentage points; blue = more often, orange = less often.
  • Case studies: three matched pairs of sessions show what these changes look like in the agent's own replies.
  • Sections: all models pooled · setup · each model separately · combinations with a clear change · case studies.

Setup

Features

How-it-works explanationsWhen the agent reports back after a change or fix, does it say why it works (or what caused the bug), not just what it did?
Next-step offersWhen the agent finishes a turn, does it offer extra work the person didn't ask for ("Want me to also add tests?")?
Shares findings about existing codeWhen the agent digs through the existing code to do a task, does it tell the person what it found (where things live, what already exists, what is missing)?
Disclosed judgment callsWhen the agent changes code, does it say what it decided on its own, what it skipped, or what the change doesn't cover?
HedgingWhen the agent isn't sure about a diagnosis or a result, does it say so?
Unchecked agreementWhen the person says something checkable (a correction, a bug report, a guess at the cause), does the agent just go along with it without checking?
Asks before actingBefore it builds something, does the agent stop and check with the person (a plan to approve, options to pick from, a clarifying question), or does it just go ahead?
Claims outrun evidenceWhen the agent says its work works, passes or is fixed, does it say so without having checked first?
Changes code when asked to explainWhen the person only asks a question (why / how / what does this do), does the agent go ahead and change the code anyway?
